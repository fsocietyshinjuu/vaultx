Here's VaultX — a fully-featured password manager

Here's everything packed in:

Security

AES-256-GCM encryption via the Web Crypto API
PBKDF2 key derivation (310,000 iterations) — same standard used by 1Password
Master password never stored anywhere, only used to derive keys
All data encrypted before hitting localStorage

Categories

Social Media, Email, Gaming, Finance, Work, Other
Crypto Wallets — special fields for wallet address, seed phrase, private key, and network/chain

Features

Password generator (cryptographically random)
Password strength meter
Show/hide & copy buttons on all sensitive fields
Search and filter by category
Export encrypted backup (.json) — safe to store anywhere
Export plaintext (for migration — clearly warned)
Import & merge from backup files
Lock vault button to return to login screen

To get started: Create a master password on first load. That's the only key to your vault — keep it safe!
